About this project

What it does

VisionAI is a research prototype for visual defect detection in smart manufacturing, built with free and open-source tools only. It has two tracks:

  • Track A — supervised defect classification. A compact CNN (with an optional ResNet-18 transfer-learning baseline) classifies steel-surface images from the NEU dataset into 6 defect types. Grad-CAM explains each decision.
  • Track B — unsupervised anomaly detection. PatchCore (pretrained features + coreset memory bank + nearest-neighbour scoring) is trained on normal MVTec AD images only, then flags and localizes defects it has never seen.

Datasets & citations

  • NEU surface defect database — 1,800 images, 6 classes. K. Song, Y. Yan, "A noise robust method based on completed local binary patterns for hot-rolled steel strip surface defects," Applied Surface Science, 2013. Free for research use (Northeastern University).
  • MVTec AD — 15 industrial categories with pixel-level defect masks. P. Bergmann et al., "MVTec AD — A Comprehensive Real-World Dataset for Unsupervised Anomaly Detection," CVPR 2019. License CC BY-NC-SA 4.0.

Scores are not calibrated probabilities

{{ calibration_note }}

Softmax outputs rank classes but are typically overconfident; anomaly scores are distances in feature space. Calibrating them (e.g. temperature scaling, conformal thresholds) is listed as future work — the dashboard never presents them as true probabilities.

Reproduce it

pip install -r requirements.txt
python scripts/download_neu.py
python src/train_classifier.py --config configs/neu_compactcnn.yaml
python src/evaluate.py --config configs/neu_compactcnn.yaml
python app/app.py   # http://127.0.0.1:5000
